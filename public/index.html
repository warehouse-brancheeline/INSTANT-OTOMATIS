WEB INSTANT

Otomatisasi print resi & panggil kurir instant (Jubelio)

Proses Instant

Kalau aktif: begitu order kurir instant muncul (dicek tiap 5 menit), langsung proses pesanan + buat & selesaikan picklist (qty penuh, TANPA verifikasi fisik) + cetak resi + siap kirim. Lalu 30 menit setelah resi dicetak (dihitung per order, bukan jam bulat): Gojek/Grab → panggil driver, kurir instant lainnya (SPX Instant, dst.) → siap kirim saja, kurir non-instant → buat pengiriman.

Pengaturan

Mode Uji Terbatas

Kalau diisi, sistem hanya memproses No. Pesanan ini — order asli lain tidak akan tersentuh. Kosongkan untuk kembali ke mode normal (semua order instant).
